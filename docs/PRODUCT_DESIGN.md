# PPOZ 产品设计文档（MVP 版）

> 版本：v0.1 · 日期：2026-08-30 · 状态：方向确认稿

## 1. 产品定位

**PPOZ 是一款朋友之间专用的游戏语音开黑软件。**

不做大而全的社区平台，只解决一件事：让一群朋友以最短的路径、最稳的音质开上黑。核心体验链路：

> 群里喊一声 → 点链接进房 → 全员开麦 → 开打

差异化主张：**进房快、音质稳、游戏全屏时不掉链子**——瞄准的是 Discord/YY 在真实开黑场景中被诟病最多的痛点。

## 2. 目标用户与场景

- **用户**：固定车队 / 开黑小圈子（3~10 人），彼此认识，无陌生人社交需求
- **设备**：以 PC 为主（开黑场景 90% 在桌面端），MVP 不做移动端
- **典型场景**：晚间约局、临时拉队、游戏全程持续通话（2~4 小时）

## 3. MVP 功能范围

### 3.1 核心（这一版必须做）

| 模块 | 功能点 | 说明 |
|------|--------|------|
| 房间 | 一键建房 | 输入昵称即可创建，无需注册账号 |
| 房间 | 链接/口令进房 | 朋友点链接直接进房，进房链路 ≤ 30 秒 |
| 语音 | 多人实时语音 | 6~10 人房间，低延迟，带降噪与回声消除 |
| 语音 | 语音控制 | 麦克风开关、静音他人、说话人高亮 |
| 语音 | 按键说话（PTT） | 支持全局热键，游戏全屏时可用 |
| 房间 | 房间管理 | 房主可踢人、锁房 |

### 3.2 暂缓（有用户反馈后再评估）

- 文字聊天、屏幕共享（微信/QQ 群已覆盖）
- 好友系统、服务器/频道体系（房间链接即入口）
- 账号体系、付费、皮肤、管理后台
- 移动端、桌面客户端打包（MVP 先做 Web 版验证）

## 4. 技术方向（概要）

| 层次 | 方案 | 理由 |
|------|------|------|
| 语音引擎 | 腾讯 TRTC / 声网 Agora，或 LiveKit 自建 | 不自研音频栈，优先国内网络质量 |
| 客户端 | Web 版（WebRTC）优先，后续 Tauri/Electron 打包桌面端 | 验证最快，分发零成本 |
| 服务端 | 轻量后端（Node/Go）管理房间状态与成员 | MVP 只需房间信令 + 成员列表 |

技术选型在立项评审时最终敲定，本文档只锁定方向：**不自研音频引擎，客户端先 Web 后桌面**。

## 5. 体验硬指标（MVP 验收标准）

1. 5 个朋友从群里点链接到全部开上麦，全程 ≤ 30 秒
2. 一局完整游戏（2 小时+）通话，无掉线、无明显音质劣化
3. 游戏全屏运行时，麦克风采集与 PTT 热键正常工作
4. 弱网（丢包 20%）下仍可通话（允许降质，不允许中断）

## 6. 里程碑

| 阶段 | 内容 |
|------|------|
| M1 | 技术选型敲定 + 项目骨架搭建 |
| M2 | 房间创建/加入 + 基础多人语音跑通 |
| M3 | 语音控制（静音/高亮/PTT）+ 房间管理 |
| M4 | 内测：自己车队真实开黑使用 2 周，修复问题后交付 MVP |

## 7. 非目标（明确不做）

- 不做陌生人匹配、公会/社区运营
- 不做直播、K 歌等泛娱乐功能
- MVP 阶段不考虑商业化
